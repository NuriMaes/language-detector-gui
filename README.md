# Language Detector GUI

A lightweight and user-friendly desktop application built with Python that automatically detects the language of any inputted text. 

## 🚀 Features
* **Real-time Detection:** Utilizes the `langdetect` library to identify the language of the text provided by the user.
* **Graphical User Interface (GUI):** Built using `tkinter` to provide a clean and intuitive desktop experience.
* **Smart Mapping:** Automatically converts short ISO language codes (like 'en', 'es', 'fr') into full, human-readable language names (e.g., 'English', 'Spanish', 'French').
* **Robust Error Handling:** Features built-in exception handling to gracefully manage empty text inputs or unrecognizable characters without crashing the application.

## 🛠️ Tech Stack
* Python 3
* Tkinter (Standard GUI Library)
* Langdetect (Language Detection Library)
